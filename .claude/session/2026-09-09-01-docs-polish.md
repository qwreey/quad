## 4. 재작성 중 소스로 전파된 발견 (실측)

- **`quad-types` 훅 주석의 관용구가 신 솔버에서 죽는다** — `q.OnCreated(function(inst: Frame) … end)`는 `Type functions do not currently
  support types of the form '*error-type*'`, `q.OnCreated<<Frame>>(fn)`만 통과(메인이 두 형태를 나란히 두고 재실측). 주석 정정,
  `typing-limits.md` 8.16, `lifecycle-hooks-plan.md` 머리 배너 정정.
- `[q.AttrKey("Hp")] = v` 해시 키는 런타임 정상이나 strict에서 생성 prop 타입에 인덱서가 없어 에러 — 문서는 배열부 `Attr`/`StringAttr`를
  안내, 소스 쪽 갭은 `todos.md`로.
- `Font = Enum.Font.X`는 Deprecated라 gen-d가 생성 `D`에서 제외(`PROP_TAG_EXCLUDE`) — 문서는 `FontFace`.
- `state:Observer(fn)`은 등록 시 1회 발화 뒤 구독 상태가 아니다(배열부에 넣거나 `:Subscribe()`) — 설계대로지만 초안 레시피 하나가 이걸
  몰라 콜백이 영영 안 불렸다. 문서 셋에 명시.
- 신 솔버 strict에서 프로퍼티 자리의 인라인 무주석 `:Compute`는 에러(`typing-limits.md` 8.13 그대로) — getting-started는 `--!nonstrict`
  가정을 명시하고 무주석 유지, how-to·skills는 타입 붙인 지역 변수.

## 6. 오후 후속 — 사용자 지시 넷 (AttrKey·Font·루트 메모·검수 계획)

사용자: *"AttrKey 는 사실 BooleanAttr(key, v) 같은 형태가 일반적이라 잘 안쓰긴 할 텐데, 에러 안 나게 할 수 있는지 보긴 한다면 좋을듯 해. Font 도 있긴 해야해.
에이전트를 통해 일괄 quad v1 에서 v2 로 마이그레이션 하는 경우(얹는게 아니라 다시 씀) 그런거 자동완성 안 먹으면 타입 문제로 못 옮길수도 있고 그럼. deprecated 를
이제 타입에 달 수 있을텐데, 검색/확인해봐야할듯. … 프로젝트 루트나 무시 대상 중 필요 없어진건 정리해도 좋아. … 다음 단계로 번역 전에 전부 검수좀 쌓아보는게 좋을듯."*

스파이크 둘(opus)·조사 하나(sonnet) 뒤 문항 넷으로 결정:
1. **Font/Deprecated**: `Font`는 Hidden 태그, `@deprecated`는 함수 전용(필드 불가), 비용 +8% — 결정 **Deprecated 전부 + Hidden `Font`/`Transparency`**, 적용은
   `ReflectionService` Write 권한 Studio 실측(`HUMAN_TODO.md` 12) 뒤. 실측·패치는 `audit/deprecated-props-spike-2026-09-09/`.
2. **AttrKey 해시 키 strict**: 인덱서 하나 제약으로 키 유니언 확장만 가능, 값은 children 유니언 — 결정 **안 함**(`attribute-plan.md`·`typing-limits.md` 8.17).
3. **루트 `-ignoreme` 메모**: 여섯 삭제(round7·ROADMAP·research에 흡수 확인), `comparison-vide-fusion` 유지(착수 대기 — `setFuncLevel` 옛 시그니처 등 stale
   있으니 쓸 때 검증). 미커버 아이디어(벤치 스위트)는 ROADMAP 백로그.
4. **검수**: 독자 페르소나 통독(초심자/v1/Fusion·Vide) + v1→v2 마이그레이션 관점 두 축 선택. 스니펫 자동 실행 게이트·Gemini 진입점은 지금 안 함 — 사용자 메모:
   luau-web(JS)에 mock을 물리면 웹 문서에서 인터랙티브 실행·스니펫 게이트가 가능하나 웹 백엔드가 없어 지금은 무의미, 가능성만 백로깅(ROADMAP).
