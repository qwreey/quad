## 4. 재작성 중 소스로 전파된 발견 (실측)

- **`quad-types` 훅 주석의 관용구가 신 솔버에서 죽는다** — `q.OnCreated(function(inst: Frame) … end)`는 `Type functions do not currently
  support types of the form '*error-type*'`, `q.OnCreated<<Frame>>(fn)`만 통과(메인이 두 형태를 나란히 두고 재실측). 주석 정정,
  `typing-limits.md` 8.16, `lifecycle-hooks-plan.md` 머리 배너 정정.
- `[q.AttrKey("Hp")] = v` 해시 키는 런타임 정상이나 strict에서 생성 prop 타입에 인덱서가 없어 에러 — 문서는 배열부 `Attr`/`StringAttr`를
  안내, 소스 쪽 갭은 `todos.md`로.
- `Font = Enum.Font.X`는 Deprecated라 gen-d가 생성 `D`에서 제외(`PROP_TAG_EXCLUDE`) — 문서는 `FontFace`.
- `state:Observer(fn)`은 등록 시 1회 발화 뒤 구독 상태가 아니다(배열부에 넣거나 `:Subscribe()`) — 설계대로지만 초안 레시피 하나가 이걸
  몰라 콜백이 영영 안 불렸다. 문서 셋에 명시.
- 신 솔버 strict에서 프로퍼티 자리의 인라인 무주석 `:Compute`는 에러(`typing-limits.md` 8.13 그대로) — getting-started는 `--!nonstrict`
  가정을 명시하고 무주석 유지, how-to·skills는 타입 붙인 지역 변수.
