## 판단·교훈

- **탐사자의 GC 실측은 클로저 포획 방식을 먼저 볼 것** — `local key = …; wk[key] = function() return key end; key = nil`은 클로저의
  업밸류 자체를 비워 아무것도 증명하지 않는다. 복사 업밸류(`local captured = key`)로 잡아야 한다. 이번엔 탐사자 결론이 기존 코드 주석과
  정반대였기에 의심했고, 재실측이 기존 설계를 지켰다.
- 이름 판정에 sonnet 둘(외부자/내부자)을 쓰는 방식이 이번에도 유효 — 두 시점이 다른 결함을 짚었고(엔진 어휘 충돌 / 코퍼스 관용구 충돌),
  메인은 둘을 합쳐 갈래 셋으로 정리만 했다.
- 재번호가 드는 장 신설은 sonnet 한 에이전트에 "작성 + 재번호 + 검증"을 묶어 맡기는 것이 가장 쌌다(발견 0, doc-check ERROR 0).
