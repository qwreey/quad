## 4. `slot:Lazy(fn)` — 사용자 착안

경과: 메인의 함수형 `Children`/핸들 안 → 사용자가 디스패치 단계에서 함수를 실체화하는 슈거를 제안(*"Defer(function() return Button() end) … derive 경로에서 호출"*) →
사용자가 스스로 다시 좁힘: *"Slot 중에서 List/Single 모양에 있어서는 실제 마운트에서 실체화잖아. 이걸 그대로 이용할 수 있지 않나"* → 메인 mock 프로토타입(`:Single` 위 슈거)으로
성립 확인 → 사용자: *"이건 변경이 없어. Source 같은게 없기 때문에, 진짜 원샷 … Effect 가 완전 필요하지 않은 경로 … 단순 얹혀서 구현하는건 안 맞지 않나"*, *"뽑고 다른 곳에 심어도 다시 실행은 없게"*,
*":Defer 실행 이후 CRUD 잠기는건 똑같게"*. 구현은 `_activateList`의 가벼운 분기(State·Observer·Effect 없음), `Quad0271`·`Quad0272`. 이름은 sonnet·Gemini 둘 다 `Lazy`
(`task.defer`와 겹침) → 사용자 *"동의. 더 어울리는 단어같아"*. 받는 컴포넌트는 평범한 Slot으로 받으면 되므로 flatten 슈거와 묶지 않은 순수 추가.
