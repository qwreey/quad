# Naming review — devui additions (a developer UI kit for Roblox), 5 groups

You are reviewing public API names for a UI kit. Judge them from the point of view of the kit's USERS (Roblox developers writing tool UIs). Everything you need is below — do not look for files. Reply in Korean, concisely: for each item your pick, a ranked shortlist, one or two reasons; flag a name that would mislead.

## Context
- devui is a Dear ImGui / Iris-inspired developer UI kit for Roblox on a reactive library (quad). Widgets are functions taking a props table and returning an Instance: `Devui.Window({ Title, Children })`, `Devui.Button({ Text, OnClick })`, `Devui.InputColor3({ Value = Source<Color3> })` (ImGui's ColorEdit3: an inline row of R/G/B fields + a swatch). Reactive values: `State<T>`, `Source<T>`.
- Existing names to stay consistent with: `Devui.OpenDialog({ Title, Children, Window?, Modal = "None"|"Window"|"Global" })` and `Devui.OpenConfirm({ Title, Text, ConfirmLabel?, CancelLabel?, OnResult = function(ok) end })` open a dialog NOW and return a handle `{ IsOpen, Close }`; `Devui.OpenMenu`; `Devui.VirtualRows({ Count, Row = function(index) ... end, RowHeight?, ScrollToRow: Source<number?>? })` is a virtualized fixed-height row list returning a ScrollingFrame. Window flags look like `NoClose`, `NoResize`. Existing pure helper modules are not public yet; these would be the first non-widget modules (they are tables of functions, not widgets).

## Names to judge
1. **Copy dialog.** Roblox game scripts have no clipboard API, so this dialog shows a read-only multi-line text box, focuses it and selects all so the user presses Ctrl+C. One open at a time. `Devui.<Name>({ Title, Text, Window?, Modal? })` -> handle. Candidates: `OpenCopyDialog`, `OpenCopyText`, `OpenClipboard`, `OpenTextCopy`, `CopyDialog`.
2. **Multi-selection rules (pure module).** `Devui.<Module>.apply(current: {key}, anchor, order: {key}, index, mode) -> (next, anchor)` where mode is single click / Ctrl-click toggle / Shift-click range from the anchor; `.prune(current, keep)` drops keys that no longer exist; `.toSet(list)`; and a helper that reads the Ctrl/Shift keys now and returns the mode. Judge: the module name (candidates `Selection`, `Select`, `MultiSelect`, `SelectRules`), the mode values (`"Single" | "Toggle" | "Range"` vs `"Replace" | "Toggle" | "Extend"`), the helper name (`modeFromKeys`, `modeNow`, `currentMode`, `keyMode`).
3. **Tree flattening (pure module, the data side of a virtual tree).** Given roots, an accessor `{ Children(node), Key(node), HasChildren(node)?, <X>(node)? }` and a set of expanded keys, returns the visible rows `{ Node, Depth, HasChildren, Expanded, More? }` in order; `.expand`/`.collapse` splice one node's subtree in place; paging shows the first N children of a node then a "load more" placeholder row; `.loadMore`, `.toggle`, `.reveal(expanded, ancestorKeys)`, `.indexOf`. `<X>(node)` returns how many children exist beyond the given list (a server tree whose children are not fetched yet; math.huge = unknown) and makes the placeholder row too. Judge: the module name (candidates `Flatten`, `TreeRows`, `FlatTree`, `VisibleRows`, `TreeView`), the accessor field `<X>` (candidates `Extra`, `Unloaded`, `Pending`, `MoreCount`), the row field `More` (count of not-shown children on a placeholder row; candidates `More`, `Remaining`, `Hidden`).
4. **VirtualRows additions.** (a) A prop that keeps the list scrolled to its end as rows are added (a log), stops when the user scrolls up, resumes when they scroll back to the bottom. Candidates: `Follow`, `FollowEnd`, `StickToEnd`, `AutoScroll`, `Tail`. (b) A function that maps a screen Y to a row index of a VirtualRows list (for drag-select / drop targets). VirtualRows is a function, so this is a separate export taking the list instance: `Devui.<Name>(list, y) -> number?`. Candidates: `RowIndexAt`, `VirtualRowAt`, `RowAt`, `IndexAtY`.
5. **Color picker.** (a) A pure colour module like an existing `ColorModel` elsewhere: HSV that keeps the hue for greys, hex parse/format, channel parsing. Candidates: `ColorModel`, `ColorMath`, `Colors`, `ColorUtil`. (b) The embeddable panel widget (saturation/value square, hue bar, R/G/B and #hex fields, preview) bound to a `Source<Color3>`: candidates `ColorPicker`, `ColorPanel`, `ColorPicker3` (ImGui's name for this panel is ColorPicker3; devui already has `InputColor3` for ImGui's ColorEdit3), `ColorEditor`. (c) The function that opens it in a dialog NOW (live apply while dragging, Cancel restores the colour it had when opened, OK keeps it): candidates `OpenColorPicker`, `OpenColorDialog`, `PickColor`. (d) `InputColor3`'s swatch opens (c) when clicked; a flag to turn that off: candidates `NoPicker`, `NoPopup`, `NoColorPicker`.
