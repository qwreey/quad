# Studio 기본 편집기 프로브 (2026-09-26) — 플래그 없이 쓰면 무엇을 잃는가

docs-review 3-1 (4)의 답을 쓰기 위한 사용자 실측 팩(HUMAN_TODO G). 질문은 하나다 — **luau-lsp·플래그 없이 Studio 기본 스크립트 편집기와 기본 nonstrict로 quad를 쓰면 무엇이 되고 무엇을 잃는가.** 메인의 예상(미실측): 런타임은 타입과 무관하니 그대로 돌고, 잃는 것은 타입 검사·자동완성의 질이다. 이 예상을 확인하거나 뒤집어 주면 문장은 에이전트가 쓴다.

## 준비

1. 이 폴더에서 `rojo serve probe.project.json` → Studio 플러그인으로 연결. `StarterPlayer/StarterPlayerScripts/editorprobe/` 아래에 `src/`의 01~03이 LocalScript로 들어가고, `ReplicatedStorage/quad-base`·`quad-roblox`도 같이 싱크된다(스크립트가 든 폴더를 `$path`로 잡으면 rojo가 중첩 프로젝트로 재귀해 죽으므로 `src/` 폴더 그대로 — 2026-09-16 실측 관용구).
2. **플래그·베타는 건드리지 말 것**이 이 프로브의 조건이다(03만 "새 타입 솔버" 베타 켜고/끄고 둘 다 보면 더 좋다). luau-lsp 플러그인이 Studio에 설치돼 있으면 잠시 비활성화.
3. 스크립트 분석 창(보기 → 스크립트 분석)을 열어 둘 것.
