CHANGELOG [Unreleased] ### Changed
  - A State placed as a Slot element (or given to `slot:Single`) whose value chain is circular (`st:Set(st)`, `a:Set(b); b:Set(a)`) is now rejected with `Quad0070` on the line that made the cycle, adding it, or mounting it; the element keeps showing its previous value and the next valid `:Set` recovers. Previously this overflowed the stack and left the Slot with a stale `Length` (the next `:Set` then raised an internal `Bookkeeping.releaseOwner` error). The `Quad0070` message now starts with `Slot:` or `StoreBind:` depending on where the cycle was found.
  (A0 갈래 — 주어를 `StoreBind:`로 고정 — 이면 마지막 문장 삭제.)

(Q114 (a)) docs/reference/core/03-state.md 또는 core/06(State를 고르는 Compute 절) 한 문단:
  - State를 고르는 계산(`outer = src:Compute(→ a 또는 b)`)이 자리에 놓여 있고 한 번의 `:Set`으로 선택과 선택된 값이 함께 바뀌면,
    자리에는 새로 선택된 쪽의 값만 쓰입니다 — 더 이상 선택되지 않은 쪽의 새 값이 잠깐 쓰이거나(숫자 키·Slot 자리에서 에러가 나던 경우 포함) 하지 않습니다.
    같은 값이 두 번 쓰일 수는 있습니다(쓰기 횟수는 약속하지 않음).
    예외: 바깥 선택이 `Blocker`/`Debounce` 뒤에서 유보 중이면 — [갈래 A] 그동안 옛 선택의 값 갱신도 화면에 반영되지 않고, 유보가 풀릴 때 한 번에 따라잡습니다
    / [갈래 A′] 게이트가 바인딩된 State 바로 위에 있으면 옛 선택을 계속 따르지만, 게이트가 선택 계산보다 위(상류)에 있으면 A와 같습니다.
    `:List`의 `updateFn`이 State를 골라 돌려주는 모양은 이 보장 밖입니다(Slot 자리에서 `Quad0156` 가능).

CHANGELOG [Unreleased] ### Changed (Q114)
  - When a State that selects another State (`outer = src:Compute(function(s) return if … then a else b end)`) is bound to a property, a numeric child position, or a Slot element, and one `:Set` changes both the selection and the selected values, only the newly selected branch is written. Previously, depending on subscription order, the branch no longer selected could be written first (a numeric child or Slot position could then fail with `Quad0160`/`Quad0156` and stay empty). While the selection itself is held by a `Blocker`/`Debounce`, updates of the previously selected branch are no longer shown until the hold is released [A′: unless the gate is directly on the bound State].
