# Naming review — devui popups (a developer UI kit for Roblox), 5 names

You are reviewing public API names for a UI kit. Judge them from the point of view of the kit's USERS (Roblox developers writing tool UIs). Everything you need is below — do not look for files. Reply in Korean, concisely: for each item your pick, a ranked shortlist, one or two reasons; flag a name that would mislead.

## Context
- devui is a Dear ImGui / Iris-inspired developer UI kit for Roblox, built on a reactive library (quad). Widgets are functions taking a props table and returning an Instance: `Devui.Button({ ... })`, `Devui.Window({ ... })`. Reactive values: `State<T>` (read-only), `Source<T>` (writable). Inspired by ImGui/Iris, not bound to follow them.
- Popups live in an `Overlay` (a full-screen layer above all windows): `overlay:Open({ Content = inst, Position = Vector2, Anchor = Vector2?, CloseOnClickOutside = boolean?, OnClose = fn? })` returns a popup handle `{ IsOpen, Close, Holder }`. `Anchor` there is the content's AnchorPoint (e.g. (0, 1) = grows upward from Position).
- Menus today: `Devui.MenuBar({ Children })` holds `Devui.Menu({ Text, Children = function(scope) return Kids(...) end })` titles; the factory builds `Devui.MenuItem({ Text, OnClick, Shortcut, Scope = scope, Hooks })`, `Devui.MenuToggle({ Text, Value | Checked + OnToggle, Scope = scope })`, nested `Devui.Menu`. Clicking an item or a toggle closes the whole menu chain. Other props in the kit: `Disabled`, `Toggled` (a button's on-look), `Hooks`, Window flags `NoClose`, `NoResize`, `NoMove`, `NoCollapse` (`NoClose` = the window has no close button).
- Roblox has a built-in `Rect` type (`Rect.new(x0, y0, x1, y1)`, fields `Min`, `Max`, `Width`, `Height`).

## Names to judge
1. **Overlay:Open option — the anchor rectangle.** An optional `Rect` (screen space) the popup is attached to — a menu-bar title, a dropdown box, a button, or a zero-size rect at the mouse for a right-click menu. Given it, the overlay keeps the popup on screen: if it overflows on one axis it flips to the other side of that rectangle (below → above, right → left), then slides inside the screen. Without it the popup is only slid inside. Candidates: `AnchorRect`, `Around`, `Attach`, `AttachTo`, `Avoid`, `Origin`. Note the existing `Anchor` option is the AnchorPoint (may clash).
2. **The popup body made public.** A Frame with the popup background, corner, border, padding and a vertical list, sized to its widest row — what a menu draws; apps building their own popups use it. `Devui.<Name>({ Children, Style?, Modifier? })`. Proposed: `PopupPanel`. Candidates: `PopupPanel`, `Popup`, `PopupFrame`, `Panel`, `PopupBody`.
3. **Open a menu at a point.** Opens the same kind of menu as `Devui.Menu` (same `Children = function(scope)` factory with MenuItem / MenuToggle / nested Menu) at an arbitrary screen point or rectangle — e.g. a right-click menu. Imperative: returns a handle with `Close`. `Devui.<Name>({ At = Vector2 | Rect, Children = function(scope) ... end, Overlay?, Style? })`. Candidates: `OpenMenu`, `ContextMenu`, `PopupMenu`, `ShowMenu`, `Menu.open` (a function on the Menu widget).
4. **A button with a menu.** One widget for two looks: with `OnClick`, a split button — the body runs `OnClick`, a narrow ▾ part at the right (own hover) opens the menu, right-click anywhere opens it; without `OnClick`, the whole button (icon/text + ▾) opens the menu (e.g. a filter button holding toggles). Takes `Text?`, `Icon?`, `OnClick?`, and the menu factory. Judge (a) the widget name — candidates `MenuButton`, `SplitButton`, `DropdownButton`, `ComboButton`; (b) the prop holding the factory — candidates `Menu`, `Children`, `Items`, `MenuItems`.
5. **Keep the menu open.** A boolean prop on `MenuToggle` (and maybe `MenuItem`): clicking it does not close the menu, so several toggles can be flipped in a row (Dear ImGui: `ImGuiSelectableFlags_DontClosePopups`). Proposed: `KeepOpen`. Candidates: `KeepOpen`, `StayOpen`, `DontClose`, `NoClose`, `Sticky`.
