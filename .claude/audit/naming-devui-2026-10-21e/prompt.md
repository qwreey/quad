# Naming review — devui additions (a developer UI kit for Roblox), 3 groups

You are reviewing public API names for a UI kit. Judge them from the point of view of the kit's USERS (Roblox developers writing tool UIs). Everything you need is below — do not look for files. Reply in Korean, concisely: for each item your pick, a ranked shortlist, one or two reasons; flag a name that would mislead.

## Context
- devui is a Dear ImGui / Iris-inspired developer UI kit for Roblox on a reactive library (quad). Widgets are functions taking a props table: `Devui.Combo<<T>>({ Text, Value: Source<T>, Options: {T} | State<{T}>, Format: ((T) -> string)?, OnChange?, Disabled?, MaxHeight? })` is a drop-down (every option is a built row — no virtualization, no search). `Devui.Table({ Columns = { { Title, Width? } }, Rows, Key, Cell = function(row: State<T>, col) ... end, Header?, RowBg?, Borders? })` builds every row. `Devui.VirtualRows({ Count, Row = function(index) ... end, RowHeight?, ScrollToRow?, Follow? })` is a virtualized fixed-height row list. `Devui.OpenMenu({ At = Vector2 | Rect, Children })` opens a menu NOW and returns `{ IsOpen, Close }`; `Devui.OpenDialog`, `Devui.OpenColorPicker` likewise. Props already in use: `Text`, `Value`, `Options`, `Format`, `OnChange`, `OnClick`, `Disabled: boolean | State<boolean>`, `Icon: string` (an image id on Button), `Hooks` (extra behaviours, e.g. a tooltip), `Placeholder` (InputText's empty-box hint).
- `Devui.Overlay` is the layer popups are drawn in; it has `Count: State<number>` = how many popups are open, tooltips included.

## Names to judge
1. **A searchable virtual list popup + the box that opens it** (like an auto-complete; for thousands of items such as "insert an Instance class").
   (a) The function that opens it NOW at a point or under a rectangle and returns `{ IsOpen, Close }`: a search box (focused on open) over a virtualized list; case-insensitive substring filter, prefix matches first; Up/Down move the highlighted row, Enter picks it, Escape closes. Candidates: `OpenSearchList`, `OpenSearch`, `OpenPicker`, `OpenFilterList`, `OpenQuickPick`.
   (b) The box widget (same `Value` / `Options` / `Format` / `OnChange` as Combo) whose click opens (a) under it. Candidates: `SearchCombo`, `ComboSearch`, `FilterCombo`, `AutoComplete`, `ComboVirtual`.
   (c) The items prop of (a): candidates `Items`, `Options` (Combo's word).
   (d) A per-item function returning a reason string when the item cannot be picked (the row is dimmed with the reason after its text, and clicking does nothing), nil when it can: candidates `Blocked`, `DisabledReason`, `Unavailable`, `Disabled` (note `Disabled` elsewhere is boolean | State<boolean>).
   (e) A per-item function returning an image id for a small icon before the text: candidates `Icon`, `IconOf`, `ItemIcon`.
   (f) The callback when an item is picked: candidates `OnPick`, `OnSelect`, `OnChoose`, `OnChange`.
2. **A virtualized table** (header row + fixed-height rows built from `VirtualRows`; columns hold text getters; one width-less column fills, columns before it stack from the left, after it from the right; row hover / selected highlight; a row click callback). (a) Widget name: candidates `VirtualTable`, `ListTable`, `DataTable`, `VirtualRowsTable`. (b) The column's text getter `(row: T) -> string`: candidates `Text`, `Get`, `Value`, `Format`. (c) The row click callback `(row: T, index: number)`: candidates `OnRowClick`, `OnClick`, `OnActivate`. (d) The selected-rows prop: a `State<{ [key]: true }>` with a `Key: (row) -> any` prop: candidates `Selected`, `SelectedKeys`, `Selection`.
3. **Overlay: how many open popups take input** (menus, combo lists, dialogs — tooltips excluded), a `State<number>` next to `Count`, so an app can ask "is a menu or dialog open?" without a tooltip counting. Candidates: `InputCount`, `BlockingCount`, `ActiveCount`, `ModalCount`, `InteractiveCount`.
