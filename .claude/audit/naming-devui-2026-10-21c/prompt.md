# Naming review — devui dialogs (a developer UI kit for Roblox), 3 items

You are reviewing public API names for a UI kit. Judge them from the point of view of the kit's USERS (Roblox developers writing tool UIs). Everything you need is below — do not look for files. Reply in Korean, concisely: for each item your pick, a ranked shortlist, one or two reasons; flag a name that would mislead.

## Context
- devui is a Dear ImGui / Iris-inspired developer UI kit for Roblox on a reactive library (quad). Widgets are functions taking a props table: `Devui.Window({ Title, Children, ... })`, `Devui.Button({ Text, OnClick })`. Reactive values: `State<T>`, `Source<T>`.
- Popups live in an overlay above every window. Existing popup API in the kit (names already chosen): `Devui.OpenMenu({ At, Children = function(scope) ... end })` opens a menu NOW and returns a handle `{ IsOpen: State<boolean>, Close: (self) -> () }`; `Devui.PopupPanel({ Children })` is the popup body; `Devui.MenuButton`, menu items take `KeepOpen = true`. Window flags are `NoClose`, `NoResize`, `NoMove`, `NoCollapse`, `NoDock`.
- A dialog differs from a popup by what it blocks while open (the user's model): nothing; only the window it was opened from (that window is dimmed and takes no input, other windows still work — it follows the window when moved / docked); or everything (the whole screen dimmed, all input taken). A dialog does not close on an outside click.

## Names to judge
1. **Open a dialog.** Opens NOW, centered on the given window (or on the screen), returns a handle like OpenMenu's: `Devui.<Name>({ Title, Children, Window = <the window's root>?, <BlockProp> = ..., OnClose? })`. Candidates: `OpenDialog`, `Dialog`, `ShowDialog`, `OpenModal`, `Modal`.
2. **What a dialog blocks.** The prop and its three values (nothing / the opener window / everything). Proposed: `Modal = "None" | "Window" | "Global"` (default "Window"; "Window" without a `Window` is an error). Candidates for the prop: `Modal`, `Blocks`, `Block`, `Scope`, `Dim`, `Modality`; for the values: `"None" | "Window" | "Global"`, `"None" | "Window" | "Screen"`, `"None" | "Window" | "All"`, `"None" | "Parent" | "App"`. Note `Scope` is already used by menus (`MenuScope`).
3. **A confirm helper** for "Delete this? [Delete] [Cancel]" in one call, on top of item 1: `Devui.<Name>({ Title, Text, <ConfirmLabel> = "Delete", <CancelLabel> = "Cancel", Window?, <BlockProp>?, <ResultCallback> = function(ok: boolean) end })`. Escape = cancel; the cancel button has the focus. Judge the function name (candidates `Confirm`, `OpenConfirm`, `ConfirmDialog`, `AskConfirm`) and the three prop names (labels: `ConfirmText`/`CancelText`, `OkText`/`CancelText`, `ConfirmLabel`/`CancelLabel`; callback: `OnResult`, `OnAnswer`, `OnConfirm` + `OnCancel` as two callbacks).
